# ניצוץ הרובוט

משחק פלטפורמה בעברית לילדים. הרובוט ניצוץ קופץ, מרחף, יורה ומסתובב כדי להציל חברים־חיות בשישה עולמות, ובסוף כל עולם מחכה לו בוס.

- 3 רמות קושי: קל, רגיל וקשה
- 6 שלבים, 18 חיות להציל ו־6 בוסים
- משחק במקלדת או בכפתורי מגע
- אפשר להתקין על מסך הבית, והמשחק עובד גם בלי אינטרנט

## הפעלה

פותחים את `index.html` בדפדפן, או את כתובת GitHub Pages של המאגר.

## מקשים

| מקש | פעולה |
|---|---|
| ← → / A D | הליכה |
| רווח / ↑ / W | קפיצה (להחזיק באוויר כדי לרחף) |
| C / F | ירי לייזר |
| X / Z | סיבוב מכה |
| ↓ / S באוויר | נחיתת רעם |
| P / Esc | הפסקה |

## עדכון המשחק

אחרי שמשנים קבצים, מעלים את המספר ב־`VERSION` שבקובץ `sw.js` (למשל `nitzotz-v2`), כדי שמכשירים שהתקינו את המשחק יקבלו את הגרסה החדשה.
